k8s Package Skill

A Green workflow for a two-node kubeadm Kubernetes cluster on DigitalOcean.

Lifecycle

./green build
./green create --dry-run
./green create
./green kubectl get nodes
./green delete

The package provisions a private VPC, one control plane and one worker; installs Flannel, DigitalOcean CCM and Flux; and verifies a GitOps-managed HTTPS application.

Safety

Keep credentials in ignored COLORS_PAR_* environment variables, never set COLORS_PAR_PROFILE, never edit .colors/, and retain compute-prevent-destroy: true.

See the configuration reference.
